# Contributing

Great first PRs:
1. Add a scheme to `schemes.json` (keep the same fields: name, who, benefit, documents, link).
2. Fix outdated amounts or eligibility. Always link the official source in your PR.
3. Add state-specific schemes.
4. Improve the README or add a web UI (Streamlit/Gradio).

Rules: use only official government sources, never guess eligibility.
